# [Diacritique](https://ergol.org/ressources/glossaire/#diacritique-def)

Signe accompagnant une lettre ou un graphème pour en modifier le sens ou la prononciation.

Exemple : la cédille pour « ç » ou les accents sur les voyelles. Plus de détails dans l’article [Wikipedia](https://fr.wikipedia.org/wiki/Diacritique).
