# [Roulement intérieur](https://ergol.org/ressources/glossaire/#roulement)

Deux touches ou plus enchainées sur une même main.

### Roulement intérieur

Roulement dans le sens de l’auriculaire vers l’index. C’est l’enchainement considéré comme le plus confortable qui soit.

### Roulement extérieur

Roulement dans le sens de l’index vers l’auriculaire.
