# Contribution site Ergo‑L

C’est avec un travail collectif que le site d’Ergo‑L est devenu une référence en matière d’ergonomie clavier.

Toute contribution, même la plus petite, est la bienvenue.
N’hésitez pas à ouvrir une [issue](https://github.com/Nuclear-Squid/ergol/issues) pour signaler un problème, qu’on n’en perde pas la trace même si ce n’est pas corrigé dans l’immédiat.

[En savoir plus](https://github.com/Nuclear-Squid/ergol/blob/main/CONTRIBUTING.md)
