# [Kalamine](https://github.com/OneDeadKey/kalamine)

Logiciel en ligne de commande permettant de créer facilement sa disposition clavier en la « dessinant » dans un fichier texte. Permet ensuite de générer les pilotes à installer pour Windows, macOS et Linux.
Les pilotes Ergo‑L sont générés via Kalamine à partir du fichier [ergol.toml](https://github.com/Nuclear-Squid/ergol/blob/main/keymaps/fr/ergol.toml)
