# [Callum mods](https://github.com/callum-oakley/qmk_firmware/tree/master/users/callum)

Sur un clavier programmable, ils sont une alternative aux Home-Row Mods (HRM) qui ne dépend pas d’un *timing*.

Le principe est d’avoir tous les *modifiers* (= *mods*) comme `Ctrl`, `Alt`, `Super`, sur un *layer* en *sticky* (comme une touche morte). On maintient la touche qui permet d’activer le *layer*, on appuie et relâche tous les *mods*nécessaires, puis en relachant la touche de *layer*, on peut ensuite appuyer sur la touche sur laquelle appliquer le ou les *mods*.

Les Callum mods sont une option activable dans [Selenium](https://onedeadkey.github.io/selenium/).
