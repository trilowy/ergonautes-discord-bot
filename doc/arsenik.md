# [Arsenik](https://github.com/OneDeadKey/arsenik)

Une configuration pensée pour les claviers classiques non programmables, permettant de profiter d’une grande partie du confort des claviers ergonomiques programmables sans devoir changer de matériel. Elle permet de rapprocher les touches éloignées et inconfortables à taper en dactylographie, tel qu’`Entrée`, `Shift`, `Backspace`, les chiffres, etc.
